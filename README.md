# seven
WIP local markdown editor

This is yet another personal project I've been working on. It's just a local markdown editor. Literally just that. Made for normal users.

<img width="1365" height="681" alt="Awesome Screenshot of the documents themselves" src="https://github.com/user-attachments/assets/ad334df6-e3b6-4e5e-957b-603974fff425"/>

The font used for content of the markdown files is [*Lora*](https://fonts.google.com/specimen/Lora), a serif I liked. The monospace font used for other things is [*Geist Mono*](https://fonts.google.com/specimen/Geist+Mono).
